# AdventureSport

## Adventure Sports Booking and Management System

### Project Description
AdventureSport is a web-based application developed to manage adventure sports activities and bookings. The system enables users to browse adventure packages, make bookings, complete payments, and submit feedback. Administrators can efficiently manage packages, bookings, payments, and customer information through a dedicated dashboard.

---

## Features

### User Features
- User Registration
- User Login and Logout
- Browse Adventure Packages
- Book Adventure Activities
- Online Payment Facility
- Submit Feedback
- View Booking Details

### Admin Features
- Secure Admin Login
- Add, Update, and Delete Adventure Packages
- Manage Bookings
- Manage Payments
- View Customer Feedback
- Generate Reports

## Installation

### Clone the Repository

git clone https://github.com/yourusername/AdventureSport.git

### Move to the Project Directory

cd AdventureSport

### Create a Virtual Environment

python -m venv venv

### Activate the Virtual Environment

#### Windows

venv\Scripts\activate

#### Linux/Mac

source venv/bin/activate

### Install Dependencies

pip install -r requirements.txt

### Apply Database Migrations

python manage.py makemigrations

python manage.py migrate

### Run the Server

python manage.py runserver

### Open in Browser

http://127.0.0.1:8000/
